# ResuScore – AI-Powered Resume Analyzer

ResuScore is a resume analysis and candidate screening application designed to help job seekers understand their resumes and help recruiters streamline the hiring process. The platform aims to evaluate resumes, generate resume scores, provide improvement insights, and support candidate evaluation through a modern, user-friendly interface.

## 🚀 Features

- **Resume Analysis:** Designed to analyze resumes and identify areas for improvement.
- **Resume Scoring:** Provides a score to help users understand their resume's overall quality.
- **Improvement Insights:** Aims to highlight areas where a resume can be improved.
- **Candidate Screening:** Designed to support recruiters in reviewing candidate information.
- **Candidate Ranking:** Intended to help compare applicants based on relevant criteria.
- **Modern UI:** Clean, professional interface with a dark theme.
- **Responsive Design:** Built with modern frontend technologies for a smooth user experience.

*Note: Feature availability depends on the current implementation and backend integration.*

## ⚙️ Installation and Setup

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/gautamrsk19-afk/Resuscore.git
```

### 2. Navigate to the project folder

```bash
cd Resuscore
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```
